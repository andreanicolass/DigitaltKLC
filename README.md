# Digitalt KLC – Digital genom konst och simulering

En webbplats som gör Elisabeth Ohlsons konstverk från **Kliniskt lärandecentrum (KLC)** vid Högskolan Väst digitalt tillgängliga. Målet är att även distansstudenter ska kunna ta del av KLC:s normkritiska lärandemiljö och reflektera kring jämlik vård och social hållbarhet.

Studentprojekt vid Högskolan Väst, våren 2026. Uppdragsgivare: Sanna Höglund Arveklev.

## Funktioner

- Digitalt galleri med Elisabeth Ohlsons konstverk
- Texter och reflektionsfrågor om normer och jämlik vård
- Webbaserad och tillgänglig, utan krav på extra programvara

## Kom igång

```bash
git clone https://github.com/andreanicolass/DigitaltKLC.git
cd DigitaltKLC
dotnet run
```

Eller öppna `DigitaltKLC.sln` i Rider eller Visual Studio.
